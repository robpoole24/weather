Add a camera

        
Paste a YouTube live/video/channel link, or a direct link to a camera image (.jpg). Set where it is — it goes straight onto the map.

        

          
          
          
        

        

          
          
          
          
          
        

        

        

      


      

        
Find live cams on YouTube

        
Searches YouTube for live cameras near a place and adds likely ones to the review queue. Costs 100 units of your daily YouTube quota per search. The location is a starting guess — adjust it before approving.

        

          
          
          
          
          
        

        

      


      

        
Bulk import a list

        
Paste a list: a place line, then its link(s) — like Venice Beach ⏎ https://www.youtube.com/live/…. Each place is looked up and the cameras land in the review queue with locations filled in.

        
        
        


        
Import a channel's live streams

        
Pulls every stream a channel has live right now (e.g. @VirtualRailfan, @earthcam), reads the place from each title and queues them. 100 quota units per 50 streams.

        

          
          
        

        

        
Import every camera from a directory site

        
For sites that list cameras (e.g. worldcams.tv/cities/, 13 pages). Reads each listing page, opens every camera
          and embeds the original stream it finds (YouTube, Nest, live video) — not the directory's page. Places come from each camera's title. Takes a few minutes for big lists.

        

          
          
          
          
        

        


        
Watched channels — checked every night for new live streams (~4 quota units each)

        

      


      


      

      

        
Check placements

        
Looks at every camera on the map, works out which country it should be in (from its source or title) and checks its pin is actually there.
          About 1 second per camera, so a big list takes several minutes. Cameras you mark "It's fine" (or move) aren't checked again.

        
        

        


        
Rejected cameras

        
Asks YouTube which cameras you rejected are live right now (about 1 quota unit per 50), so you can bring back any you turned down by mistake.
