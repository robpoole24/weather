🔧 Channel Tools
Mark Channel Live Manually
Zero quota cost — directly sets a channel's live status. Use when you know a stream is live but notifications missed it. Get the video ID from the YouTube URL: youtube.com/watch?v=VIDEO_ID
Channel ID Validator
Verify a channel ID resolves to a real YouTube channel before adding it. Costs 1 quota unit.
Live Stream Lookup
Check if a channel is currently live via the YouTube API. Costs 100 quota units. Only use when you don't know the video ID. Disabled when quota is exceeded.
